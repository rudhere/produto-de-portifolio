# PhotoJournalist Portfolio

Aplicação web profissional para criação de portfólio de repórter fotográfico com visual editorial premium.

## Funcionalidades

- Editor de perfil profissional com foto e biografia
- Gerenciador de reportagens com galeria de imagens
- Grid editorial com layouts de foto (1/2, largura total, vertical 2x, grande 2x2)
- Páginas automáticas: capa (3 templates), sumário, sobre mim, reportagens, equipamentos, competências, publicações, contato
- Visualização em tempo real no formato A4
- Exportação em PDF, HTML e JSON
- Importação de projetos via JSON
- Modo escuro
- Marca d'água configurável
- Salvamento automático no navegador (LocalStorage)
- Design responsivo

## Tecnologias

- HTML5, CSS3, JavaScript puro
- Google Fonts (Bebas Neue, Oswald, Montserrat, Inter, Roboto, Source Sans 3)
- html2canvas, jsPDF, SortableJS (CDN)

## Como usar

Abra o arquivo `index.html` no navegador. Nenhum servidor ou dependência de backend é necessário.
